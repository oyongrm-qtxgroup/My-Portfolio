### A voice that behaves like a receptionist

Turn-detection so the agent stops talking over people. One admin-controlled brand voice per practice, with per-country accents on the demo numbers. The accent used to be re-rolled on every call, so a practice could hear an Australian voice one hour and an American one the next; I found the cause and removed it. The receptionist also knows the real date, time and time zone on every call, so "next Tuesday" means the right day.

### One script, three practice systems

Integrations with CareStack, Core Practice (OAuth) and Dentally behind a single receptionist script. Callers are matched by the number they ring from, even when the name on file is spelt differently, and an appointment is found from the day and time the caller gives.

### Script changes are tested before they go live

Practices ask for script changes in plain English, with an AI assistant that drafts the rewrite. Before an admin approves, they run test conversations against the proposed script: standard scenarios, custom ones, or replays of real call transcripts. Every version is kept, scored and can be restored, and practices can't see or copy the prompt behind their receptionist.

### The business around it

Trials that set up the receptionist automatically, Stripe subscriptions kept in sync, a premium tier with custom voices and a grace period on downgrade, referral commissions, and a landing page with live demo numbers you can ring.

<Section label="§ 2 Keeping it up">

Every failed AI reply is logged and alerts the admins, and a check runs every 15 minutes, after an outage once went unnoticed for days. The end-to-end tests are back on in the release pipeline without overloading the live database. Script changes sync safely across environments. The unglamorous part of the job, and most of the reason it stays live.
