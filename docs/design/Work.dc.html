§ 1
What I built

A voice that behaves like a receptionist

Turn-detection so the agent stops talking over people. One admin-controlled brand voice per practice, with per-country accents on the demo numbers. Fixing why the AI sounded different from one call to the next. A recording notice at the start of every call.

One script, three practice systems

Integrations with CareStack, Core Practice (OAuth) and Dentally, behind a single receptionist script. Caller-identity matching against patient records, and the bug where appointment search found nothing even when times were free.

Script changes are tested before they go live

Practices ask for script changes in plain English, with an AI assistant that drafts the rewrite. Before an admin approves, they run test conversations against the proposed prompt: standard scenarios, custom ones, or replays of real call transcripts. Every version is kept and can be restored; rejections keep their history.

The business around it

Trials that set up the receptionist automatically, Stripe subscriptions kept in sync, a premium tier with custom voices and grace periods, referral commissions, and a landing page with live demo numbers you can ring.

One practice owner's script went through eleven rounds of review before they were happy with it. The review workflow exists because of that.

Prospects hear their own accent: each country gets its own demo number.

Keeping it up

A monitor that flags AI-service outages before practices notice them. Script changes that sync safely across environments. A production database that was running out of disk. The unglamorous part of the job, and most of the reason it stays live.
